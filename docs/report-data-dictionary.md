# قاموس بيانات التقارير

| المصطلح | المعنى | ما لا يعنيه |
|---|---|---|
| سجل أصلي | السجل الذي يمثل عملًا أساسيًا في حساب المستخدم | لا يعني أن محتواه مكتمل أو معتمد |
| نسخة مشتقة | نسخة مرتبطة بأصل أو ناتجة عن تحرير/استيراد | لا تُحسب كأصل مستقل دون قاعدة واضحة |
| مكتمل | حالة صريحة مسجلة في المصدر | لا تُستنتج من وجود نص أو تاريخ |
| غير معروف | لم توجد حالة مصدر قابلة للتفسير | لا يعني أن السجل ناقص |
| غير متاح | تعذر الوصول إلى محتوى المصدر أو لم يُنقل للجهاز | لا يُحتسب صفرًا |
| فهرس جزئي | تتوفر معرفات أو بيانات مختصرة دون المحتوى الكامل | لا يكفي للحكم على اكتمال السجل |
| خطة مرجعية | مادة تساعد التخطيط والبحث | ليست إثباتًا لتنفيذ البرنامج |
| تدخل مقترح | صياغة أولية تحتاج مراجعة واعتمادًا مهنيًا | ليس تشخيصًا ولا قرارًا آليًا |
| تغير قبلي/بعدي | فرق وصفي بين قياسين | لا يثبت السببية منفردًا |

## متطلبات كل تقرير

يجب أن يعرض التقرير فترة البيانات، وقت آخر تحديث، عدد السجلات المستخدمة، عدد المستبعدة وسبب الاستبعاد، وحالة توفر كل مصدر. عند عدم توفر مصدر، استخدم «غير متاح» بدل `0` أو قيمة افتراضية.
