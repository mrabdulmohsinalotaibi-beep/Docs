# إعداد Microsoft OneDrive — مستندات الذات

## المرحلة الحالية
هذا الفرع يضيف مؤشر OneDrive مستقلاً ولوحة إعداد تتحقق من توفر معرف تطبيق Microsoft عبر `GET /api/onedrive/config`. **لا ينفذ هذا الفرع OAuth أو رفع النسخ أو استعادتها، ولا يجوز نشره باعتبار النسخ السحابي عاملاً.**

## تسجيل تطبيق Microsoft (يتطلب مالك التطبيق)
1. افتح Microsoft Entra admin center > App registrations > New registration.
2. سمّ التطبيق `ATHAT Docs Backup`. اختر أنواع الحسابات المتوافقة مع الجمهور المقصود؛ `Files.ReadWrite.AppFolder` قد يختلف توافره للحسابات الشخصية والعمل/المدرسة، لذا تحقق من دعم كل فئة قبل اعتمادها.
3. أضف Platform **Single-page application** وRedirect URI هو `https://docs.athat.app/` (مطابقة تامة).
4. استخدم OAuth 2.0 Authorization Code + PKCE فقط. لا تستخدم implicit flow ولا تضع Client Secret في كود المتصفح.
5. اطلب أقل نطاق ملفات متاح حسب نوع الحساب: `Files.ReadWrite.AppFolder` للحساب الشخصي المدعوم، دون طلب صلاحية وصول شامل إلى ملفات المستخدم إلا إن كان هناك سبب تقني موثق وموافقة منفصلة.
6. احفظ **Application (client) ID** فقط في إعداد Worker `athat-docs` بالمتغير `DOCS_ONEDRIVE_CLIENT_ID`. لا تضف رموز وصول أو كلمة مرور إلى GitHub. لا يعني وجود هذا المتغير نجاح الربط.
7. اختبار الحساب الشخصي والحساب المدرسي إن كان مدعومًا، وحالة رفض التفويض، ثم سحب الصلاحية.

## الخطوات البرمجية المتبقية قبل تفعيل الزر
- واجهة OAuth آمنة مع state والتحقق من مستخدم Docs وحماية جلسات الحسابات على الجهاز.
- مفاتيح تشفير مستقلة وعبارة استعادة يحتفظ بها المستخدم؛ يجب ألا يخزن الخادم مفتاح فك التشفير.
- إنشاء حزمة كاملة من بيانات IndexedDB والسجلات والمرفقات المنقولة والتحقق من الفهارس؛ امنع نجاح نسخ جزئية على أنها كاملة.
- الرفع إلى OneDrive باستخدام Microsoft Graph إلى app folder؛ التعامل مع الملفات الكبيرة عبر upload sessions، وإعادة المحاولة عند فشل الشبكة، والتحقق من نتيجة الرفع.
- تجديد التفويض بطريقة آمنة مع منع تخزين access/refresh tokens في localStorage كنص واضح.
- طابور محلي دائم للمزامنة: يتحرك عند فتح التطبيق أو استعادة اتصاله، دون وعد بالعمل عندما يكون PWA مغلقًا.
- نسخ مؤرخة محفوظة مدة 60 يومًا مع عدم إزالة آخر نسخة صالحة عند انتهاء المهلة. لا تحذف نسخة سابقة قبل إثبات سلامة الحالية.
- استعادة اختبارية مستقلة: التحقق من هوية الحساب، وفك التشفير، واكتمال المرفقات، ودمج النسخ دون استبدال صامت.

## دلالة المؤشرات
- الأخضر لحفظ الجهاز فقط بعد نجاح الكتابة والتحقق.
- الأصفر عند انتظار الرفع أو نقص الاتصال.
- الأخضر لمؤشر OneDrive بعد إثبات اكتمال رفع نسخة مشفرة قابلة للاستعادة.
- الأحمر عند فشل الرفع أو غياب الربط، مع عدم مساس هذا بالفهرس المحلي.

## اختبارات النشر
- `node scripts/build-worker.mjs --check`
- `node --check worker.js`
- `node --test tests/official-a4.test.mjs`
- `node --test tests/peer-sync.test.mjs`
- اختبار متصفح حقيقي Android + iPhone؛ اختبار انقطاع اتصال وحزمة أكبر من 4 MiB واستعادة ناجحة على حساب اختباري.
- لا تدمج/تنشر هذا الفرع دون اكتمال OAuth/Graph والتشفير واختبارات الاستعادة.
