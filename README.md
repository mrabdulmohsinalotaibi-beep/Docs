# مستندات الذات | ATHAT Docs

الموقع: https://docs.athat.app

موقع مستقل وخفيف لإدارة مستندات A4 والأرشفة وملف الإنجاز، بدون قاعدة بيانات سحابية.

## الميزات
- قوالب A4 قابلة للتحرير والطباعة أو حفظ PDF من المتصفح.
- أرشيف مسودات وأعمال مكتملة ومؤرشفة.
- حفظ صور الشواهد داخل المستند المحلي.
- استيراد XLS/XLSX/CSV مع معاينة وموافقة قبل الحفظ، باستخدام SheetJS عند توفر الشبكة.
- اختيار مستندات وطباعة ملف إنجاز بغلاف وفهرس.
- تنزيل واستعادة نسخ احتياطية JSON.

## الحماية والقيود
- المستندات والصور تُحفظ في IndexedDB **على جهاز المستخدم فقط**، مع فصل قواعد البيانات لكل معرّف حساب. تسجيل الدخول الحالي من خدمة حسابات الذات بالبريد وكلمة المرور، وليس برمز بريد OTP بعد. لا تُخزّن المستندات في D1/R2.
- يوجد فرع تجريبي لمزامنة الأجهزة المباشرة عبر WebRTC، وتتطلب تشغيل الجهازين وتبادل رموز SDP يدويًا وتسجيل الدخول بنفس الحساب والموافقة قبل النقل والاستيراد. دون اتصال WebRTC يجب استخدام ملف النسخة الاحتياطية.
- مسح بيانات المتصفح قد يمحو الأعمال. احفظ نسخة احتياطية دورية؛ حفظها في خدمة سحابية قرار المستخدم.
- لا تستورد بيانات الطلاب الحساسة على أجهزة عامة أو مشتركة.
- الموقع غير مربوط مباشرة ببيانات AAA أو سجلات مستخدميه.
- نسخ ملفات Excel لا يستعيد صور المرفقات الأصلية بمجرد ذكر أسمائها.
- استيراد XLSX يحتاج مكتبة SheetJS من CDN؛ سائر وظائف المستندات محلية.

## النشر
يتضمن الملف `worker.js` كامل الصفحة والتطبيق. نُشر Worker باسم `athat-docs` على Cloudflare وربط Custom Domain `docs.athat.app`. مصدر الحقيقة هو هذا المستودع، لكن نشر التعديلات التالية يحتاج تحديث Worker مباشرة أو إعداد نشر مستقل؛ لا يوجد GitHub Actions مفعل في هذا المشروع.

## نقل المستندات بين جهازين (فرع تجريبي)
- افتح الموقع في الجهازين وسجّل الدخول بنفس الحساب الحالي، ثم اضغط «مزامنة أجهزتي».
- من الجهاز الأول اختر «إنشاء اتصال»، وانسخ الرمز الناتج إلى الجهاز الثاني بطريقة خاصة.
- في الجهاز الثاني الصق الرمز واختر «قبول اتصال»، ثم انسخ الاستجابة إلى الجهاز الأول.
- في الجهاز الأول الصق الاستجابة واضغط «إتمام الاتصال». عند الاتصال اضغط «إرسال مستنداتي»، ثم وافق على الاستيراد في الجهاز الآخر.
- النقل عبر WebRTC DataChannel؛ لا توجد API لرفع المستندات إلى خادم. خادم STUN لا يحتفظ بمحتوى المستندات. لم يُضف TURN؛ بعض الشبكات لن تتصل.
- **مهم:** هذا نقل يدوي باتجاه واحد لكل مرة وليس مزامنة خلفية آلية أو ضمانًا لاستعادة البيانات بعد فقدان الأجهزة. التغييرات المتعارضة تحفظ كنسخ إضافية، ويجب مراجعتها. يدعم حتى 32 MiB من مستندات JSON في النقل الواحد.
- يعتمد الربط الحالي على تبادل رموز الاتصال والموافقة اليدوية؛ لم تُنفَّذ بعد قائمة أجهزة موثوقة قابلة للإلغاء أو تحقق هوية متبادل مستقل عن رموز الربط.
- حسابات البريد وكلمة المرور القائمة محفوظة كما هي. يتطلب تسجيل الدخول باستخدام OTP آلية توليد/إرسال/التحقق من رموز البريد آمنة مع محددات محاولات، وخدمة بريد موثوقة. لا تضع مفتاح البريد في المستودع.
- العمل دون إنترنت داخل الصفحة المفتوحة مدعوم؛ فتح الموقع من الصفر بلا شبكة يتطلب تخزين ملفات التطبيق مسبقًا عبر Service Worker، وهو خارج هذا التغيير.
- إذا بدّلت نطاق الموقع أو مسحت بيانات المتصفح لن تنتقل IndexedDB تلقائيًا. خذ نسخة احتياطية محلية قبل التحديث.
