# مستندات الذات | ATHAT Docs

الموقع: https://docs.athat.app

موقع مستقل وخفيف لإدارة مستندات A4 والأرشفة وملف الإنجاز، بدون قاعدة بيانات سحابية.

## الميزات
- قوالب A4 قابلة للتحرير والطباعة أو حفظ PDF من المتصفح.
- أرشيف مسودات وأعمال مكتملة ومؤرشفة.
- حفظ صور الشواهد داخل المستند المحلي.
- استيراد XLS/XLSX/CSV مع معاينة وموافقة قبل الحفظ، باستخدام SheetJS عند توفر الشبكة.
- اختيار مستندات وطباعة ملف إنجاز بغلاف وفهرس.
- تنزيل واستعادة نسخ احتياطية JSON.

## الحماية والقيود
- البيانات تحفظ في IndexedDB **على جهاز المستخدم فقط**. لا يوجد تسجيل دخول أو مزامنة حسابات أو D1/R2.
- البيانات لا تنتقل بين الأجهزة دون تنزيل واستعادة نسخة احتياطية يدويًا.
- مسح بيانات المتصفح قد يمحو الأعمال. احفظ نسخة احتياطية دورية؛ حفظها في خدمة سحابية قرار المستخدم.
- لا تستورد بيانات الطلاب الحساسة على أجهزة عامة أو مشتركة.
- الموقع غير مربوط مباشرة ببيانات AAA أو سجلات مستخدميه.
- نسخ ملفات Excel لا يستعيد صور المرفقات الأصلية بمجرد ذكر أسمائها.
- استيراد XLSX يحتاج مكتبة SheetJS من CDN؛ سائر وظائف المستندات محلية.

## النشر
يتضمن الملف `worker.js` كامل الصفحة والتطبيق. نُشر Worker باسم `athat-docs` على Cloudflare وربط Custom Domain `docs.athat.app`. مصدر الحقيقة هو هذا المستودع، لكن نشر التعديلات التالية يحتاج تحديث Worker مباشرة أو إعداد نشر مستقل؛ لا يوجد GitHub Actions مفعل في هذا المشروع.
