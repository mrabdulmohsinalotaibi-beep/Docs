# مستندات الذات | ATHAT Docs

الموقع: https://docs.athat.app

موقع مستقل وخفيف لإدارة مستندات A4 والأرشفة وملف الإنجاز، بدون قاعدة بيانات سحابية.

## الميزات
- قوالب A4 قابلة للتحرير والطباعة أو حفظ PDF من المتصفح.
- أرشيف مسودات وأعمال مكتملة ومؤرشفة.
- حفظ صور الشواهد داخل المستند المحلي.
- استيراد XLS/XLSX/CSV مع معاينة وموافقة قبل الحفظ، باستخدام SheetJS عند توفر الشبكة.
- اختيار مستندات وطباعة ملف إنجاز بغلاف وفهرس.
- تنزيل واستعادة نسخ احتياطية JSON.

## الحماية والقيود
- البيانات تحفظ في IndexedDB **على جهاز المستخدم فقط**. لا يوجد تسجيل دخول أو مزامنة حسابات أو D1/R2.
- البيانات لا تنتقل بين الأجهزة دون تنزيل واستعادة نسخة احتياطية يدويًا.
- مسح بيانات المتصفح قد يمحو الأعمال. احفظ نسخة احتياطية دورية؛ حفظها في خدمة سحابية قرار المستخدم.
- لا تستورد بيانات الطلاب الحساسة على أجهزة عامة أو مشتركة.
- الموقع غير مربوط مباشرة ببيانات AAA أو سجلات مستخدميه.
- نسخ ملفات Excel لا يستعيد صور المرفقات الأصلية بمجرد ذكر أسمائها.
- استيراد XLSX يحتاج مكتبة SheetJS من CDN؛ سائر وظائف المستندات محلية.

## النشر
يتضمن الملف `worker.js` كامل الصفحة والتطبيق. نُشر Worker باسم `athat-docs` على Cloudflare وربط Custom Domain `docs.athat.app`. مصدر الحقيقة هو هذا المستودع، لكن نشر التعديلات التالية يحتاج تحديث Worker مباشرة أو إعداد نشر مستقل؛ لا يوجد GitHub Actions مفعل في هذا المشروع.

## كليشة A4 الرسمية والتصنيفات (1448 هـ)
- تمت إضافة صورة الشعار المعتمد المستخدم في مستودع AAA (المسار: `public/moe-user-official.svg`) وتضمينها في الصفحة وملفات الطباعة دون طلب تحميل خارجي.
- يُعبّئ صاحب الحساب ملفه المحلي مرة واحدة: اسم المدرسة، إدارة التعليم، اسم الموجّه الطلابي، المرحلة الدراسية. الاسم يأتي تلقائيًا من حسابه إن توفر؛ المدرسة والإدارة تُقرأ من بيانات الحساب إذا أعادها الخادم، وإلا تُحفظ إعداداتهما المحلية على الجهاز.
- يتولّد التاريخ هجريًا بتقويم أم القرى عند إنشاء المستند؛ يمكن تغييره يدويًا.
- التوقيع بالقلم أو اللمس محفوظ داخل سجل IndexedDB بصيغة PNG ومرفق بنسخة PDF.
- السجلات موزعة على 11 تصنيفًا رئيسيًا وأقسام فرعية مستمدة من `AAA/src/guidance-a4-classification.ts`. لا تتم قراءة بيانات الطلاب أو تغيير المستندات القديمة.
- قائمة الأسابيع 1–18 للفصل الأول 1448 هجريًا من `AAA/src/guidance-semester-plan-1448.ts`. هذه خطة أعمال مرجعية وليست إثباتًا للتنفيذ أو جدولًا رسميًا لجميع إدارات التعليم.
- تُحفظ الصور والشواهد ضمن المستند نفسه وتُدرج في PDF. نموذج الطباعة يعرض الحقول الفارغة افتراضيًا بدل صفحة شبه فارغة.
- إعدادات ملف المدرسة محفوظة على جهاز المستخدم ضمن مفتاح مرتبط بمعرّف الحساب، ولا تُرسل للخادم. نقلها إلى جهاز آخر يتطلب إدخالها هناك أو نقل بيانات المستخدم بطريقة مصرح بها.
